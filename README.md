# SBT-DF204-Case-Study-5-Investigating-DJI-Mavic-Air-Flight-Evidence
This case study examines DJI Mavic Air evidence from an Android logical acquisition of the dji.go.v4 application. The investigation identifies and interprets four families of DJI GO 4 artefacts — main flight records (TXT), cached video (MP4), detailed flight records (DAT), and cached pictures (JPEG).
